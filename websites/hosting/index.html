Uptime and monitoring

We know the site is down before you do.

  • 99.99% uptime. That is the standard we run to.
  • Outside monitoring. A service outside our own network checks your site around the clock, so an outage on our side can't hide itself.
  • Same-day response. If your site goes down, we respond the same day.
  • Its own space. Each site runs in its own isolated space, so a problem on another site can't reach yours.
Access and security

No password is the only thing protecting your site.

  • One-time code sign-in. Nobody signs in with a password alone. Sign-in uses a one-time code sent to your email.
  • A global security network in front of every site. It handles DNS, attack protection, and encryption.
  • Nightly file checks. We check your site's files every night for changes that shouldn't be there.
  • Next-business-day security fixes. When a security issue is found, we fix it by the next business day.
Backups and updates

Every night a copy, every week a patch.

  • Nightly backups. Your site is backed up every night.
  • 30-day database retention. We keep 30 days of database backups, so we can restore to a point before a mistake.
  • Weekly updates. Core software, themes, and plugins are updated every week.

Questions

Common questions about hosting and security

What uptime do you run to?

We come from telecom, where uptime is counted in nines. We engineer the platform for 99.99% uptime and monitor every site from outside our own network. If a site goes down, we respond the same day. 99.99% is the standard we run to, not a contractual service credit.

How do I sign in to my site?

Sign-in uses a one-time code sent to your email. No account relies on a password alone.

How long do you keep backups?

Backups run every night. We keep 30 days of database backups, so we can restore to an earlier point.

How fast do you fix security problems?

Security fixes go in by the next business day. Routine updates run weekly.

Can my team update content with AI tools?

Yes. Your team can use Cursor, Codex, Claude, or Grok through a secure connection limited to your site. The tool can reach your site and nothing else.

Can I bring my existing site?

Yes. We move WordPress, Drupal, and static sites as they stand, test on a private address, and cut over when it passes. See website migrations.
